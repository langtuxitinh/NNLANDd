Java · Maven · NetBeans · MySQL. Ảnh và font được đóng gói cục bộ.

1. Điền kết nối MySQL của máy bạn

Bật MySQL. Sao chép application-local.properties.example thành application-local.properties ngay cạnh pom.xml, rồi điền mật khẩu và tài khoản của bạn.

spring.datasource.username=root
spring.datasource.password=MAT_KHAU_MYSQL_CUA_BAN

Database mặc định là nnland. Ứng dụng tự tạo bảng và 6 tòa/30 căn mẫu lần đầu. Không cần import script cũ trong thư mục database/legacy.

2. Chạy ứng dụng

Trong NetBeans: File → Open Project → chọn thư mục có pom.xml → Clean and Build → Run Project. Nếu cần, chạy Maven goal spring-boot:run. Dùng JDK 8 trở lên.

Chạy trực tiếp trên Windows: sau khi điền cấu hình và cài Java, nhấp RUN_NNLAND.bat. Bản WAR đã có trong target/NNland.war.

Đợi nhật ký báo khởi động xong rồi mở:

Mở NNland tại localhost:8081 →
